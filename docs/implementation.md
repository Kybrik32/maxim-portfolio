# Maxim portfolio — design and implementation

React + Vite + CSS portfolio. Swiss / corporate editorial direction with cool light gray, dark typography, restrained blue accent, system Arial/Helvetica, and a consistent grid. No fabricated clients, metrics, or testimonials.

1. Build semantic single-page structure with native anchor navigation and working contact links.
2. Keep project content in src/projects.js and render reusable ProjectCard components. IRON & DUST is a fictional workshop concept. OKOM-TECH is an independent redesign concept, with a separate case study and an explicit non-affiliation disclaimer.
3. Use an actual project screenshot, responsive WebP sizes, reserved image dimensions, and reduced-motion support.
4. Add page metadata, favicon, social preview, and local run instructions.
5. Run npm run build; check 320–768 px and desktop layouts, keyboard navigation, anchor targets, and image loading.

The redesign kept the original content architecture and external URLs. It changed display copy to direct commercial language and removed decorative italic type.
